
# 🎮 UNDERGLOW: THE LOST REALM

A Fantasy Adventure and Puzzle Game.

## 🌌 About the Game

UNDERGLOW: THE LOST REALM is a fantasy adventure game where players explore a mysterious magical world, collect four magical crystals, solve puzzles, and unlock new levels.

## 🎯 Game Objective

Restore the lost realm by collecting crystals, solving the Ancient Gate puzzle, and unlocking the ancient portal.

## 🧙 Characters

- **Zyra:** Shadow Jumper
- **Kael:** Light Keeper
- **Nova:** Tech Alchemist
- **Rune:** Crystal Master

## ✨ Features

- Magical fantasy environment
- Crystal collection system
- Platform-based movement
- Puzzle challenges
- Guardian interaction
- Level progression

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
